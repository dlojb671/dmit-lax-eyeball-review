## 路由线路：三网怎么走，联通移动用户看重点

EB.WEE 的线路不是 CN2 GIA，这一点要先说清楚。它走的是 **Eyeball 网络配置文件**，具体来说：

**回程**（机器 → 国内）：
- 移动：CMIN2（中国移动国际精品网络）
- 联通：AS9929
- 电信：9929/CMIN2 负载均衡

**去程**（国内 → 机器）：
- 联通和电信：CN2 骨干网直连
- 移动：CMIN2

实测三网延迟普遍落在 130–170ms 之间，江苏、上海等节点晚高峰也基本稳住，丢包率低。电信用户可能偶尔感觉没有 CN2 GIA 那么稳定，但联通和移动用户用下来整体体验和 Premium 套餐差距不大，日常代理和中转跑起来没有明显卡顿。

NAT 类型是开放网络，**端口全开放**，不用担心 NAT 穿透问题，自建各种服务很方便。
